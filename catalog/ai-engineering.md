# AI Engineering

Agent harnesses, reasoning loops, and AI-codebase best practices.

## pstack (community / original) — `cursor/plugins`

> pstack by [@poteto](https://github.com/poteto) (Lauren Tan) — an OpenCode port of Cursor's agent harness. Model-configurable reasoning loop with a set of engineering principles.

**Install via the Cursor plugin (official):**

```
/plugin install pstack@cursor-plugins
```

**Or install the skill directly:**

```bash
npx skills add https://github.com/cursor/plugins/tree/main/pstack
```

Browse: [github.com/cursor/plugins/tree/main/pstack](https://github.com/cursor/plugins/tree/main/pstack)

> **Note:** The `pstack-*`, `poteto-*`, and `principle-*` skills in [`../skills/`](../skills) are **your customized OpenCode copy** of this family — they differ from the upstream plugin. Keep upstream as reference; your versions are the installable ones.
